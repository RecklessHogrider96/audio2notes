How it works

  1. Decode the MP3 and measure the energy of every piano key over time (one tuned filter per key).
  2. At each moment a new sound starts, pick the strongest new key, remove its overtones, and repeat. This is what separates real chord notes from harmonics.
  3. Tighten each note's start time, then track how long it rings to get its length.
  4. Write a MIDI file, which this player turns into a falling-keys lesson.

Try your own

Load any MIDI file with "Load .mid file", whether it's a Basic Pitch output from your own recording or a .mid from the transcription script.

Limits of this POC

The test recordings are synthesized piano with light reverb, so real phone recordings with heavy sustain pedal and dense chords will score lower. A production version would replace the signal-processing core with a trained piano model (e.g. ByteDance's piano transcription or Basic Pitch) and add beat and measure detection for sheet music.
